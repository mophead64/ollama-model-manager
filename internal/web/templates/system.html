Ollama {{$u.Latest}} is out{{if not $u.Published.IsZero}} ({{ago $u.Published}}){{end}}. Keeping Ollama up to date matters more than for most apps:

  • New models need it. Recently released models often use architectures older versions can't load, so they fail to download or run (“requires a newer version of Ollama”, “unknown model architecture”).
  • Downloads from Hugging Face rely on it too: older versions can't follow some of its newer download hosts.
  • Speed, memory use and GPU support improve from release to release, along with fixes for tool calling, templates and bugs.

The release notes ↗ say what's changed in this one. How to update depends on how Ollama was installed:

Docker Compose (recommended)

From the folder with your docker-compose.yml, pull the new image and recreate the container. Models are kept in the volume.

{{template "copy_cmd" (copycmd "upd-compose" "docker compose pull ollama && docker compose up -d ollama")}}
docker run

Pull the new image, then remove and recreate the container with the same options you started it with (volume, ports, GPUs):

{{template "copy_cmd" (copycmd "upd-docker" "docker pull ollama/ollama:latest")}} {{template "copy_cmd" (copycmd "upd-docker-run" "docker stop ollama && docker rm ollama && docker run -d --gpus=all -v ollama:/root/.ollama -p 11434:11434 --name ollama --restart unless-stopped ollama/ollama")}}
Linux (install script)

Re-running the installer updates Ollama in place:

{{template "copy_cmd" (copycmd "upd-linux" "curl -fsSL https://ollama.com/install.sh | sh")}}

Back up your service settings first. The installer rewrites /etc/systemd/system/ollama.service, so anything added to it directly (OLLAMA_HOST, OLLAMA_MODELS, OLLAMA_KEEP_ALIVE…) is lost:

{{template "copy_cmd" (copycmd "upd-backup" "sudo cp /etc/systemd/system/ollama.service ~/ollama.service.bak")}}

To stop it happening again, keep them in an override, which updates leave alone: sudo systemctl edit ollama, then add them under [Service] as Environment="OLLAMA_HOST=0.0.0.0". Afterwards:

{{template "copy_cmd" (copycmd "upd-restart" "sudo systemctl daemon-reload && sudo systemctl restart ollama")}}
macOS or Windows

The Ollama app updates itself: when an update's ready, choose Restart to update from its menu bar or tray icon. Or download the latest from ollama.com/download ↗. With Homebrew:

{{template "copy_cmd" (copycmd "upd-brew" "brew upgrade ollama && brew services restart ollama")}}

Updating restarts Ollama: loaded models are unloaded, and downloads in progress pause (this app resumes them). Downloaded models are kept. It's worth a look at the release notes ↗ for anything that's changed, and running ollama --version afterwards to check.
