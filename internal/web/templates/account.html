Ollama downloads models from Hugging Face itself. To pull gated or private repos, Ollama needs linking to a Hugging Face account with access to them. This links Ollama, not you: everyone using this Ollama can then pull what that account can.

1. Add Ollama's key to Hugging Face

{{if .Key}}

The public half of the key Ollama at {{.OllamaURL}} signs its requests with. It's safe to share: it can only check Ollama's signature, not make one.

{{else if .KeyUnavailable}}

Ollama didn't report its key: it only does while it isn't signed in to ollama.com. Print it on the machine running Ollama:

cat ~/.ollama/id_ed25519.pub

For Ollama's Linux service, sudo cat /usr/share/ollama/.ollama/id_ed25519.pub; for Ollama in Docker, docker exec <container> cat /root/.ollama/id_ed25519.pub.

{{else}}
Couldn't ask Ollama for its key: {{.KeyErr}}
{{end}}

Then, signed in to Hugging Face, open Settings → SSH and GPG Keys ↗, choose Add SSH key and paste it in. Any title will do, such as “Ollama”.

2. Accept gated models' terms

Gated repos, marked gated on Discover, also need their terms accepted once, on the model's Hugging Face page, by the same account. Some are approved straight away; others take a while.

3. Download

Downloads of those repos now work. This app can't test the link without downloading something, so if one fails with an access error, its page says what to check.

Browsing private repos (optional)

{{if .HasToken}} {{with .TokenUser}}

Token set This app uses a Hugging Face token for {{.}}: Discover includes the private repos it can see, and downloads are checked with it. Everyone using this app sees what the token can.

{{else}}
HF_TOKEN is set, but it doesn't work: {{.TokenErr}}
{{end}} {{else}}

This app talks to Hugging Face anonymously, so Discover can't list private repos, and download checks can't see into them. To change that, create a read access token under Settings → Access Tokens ↗, set it as HF_TOKEN in this app's environment, and restart it. Everyone using this app will see what the token can. Ollama's downloads don't need it: they use the key above.
